# MVP 剧情演出表（山道遭遇战）

## 1. 目的

本文档把 `story-mvp-script.md` 的对白文本拆成演出执行表，供剧情策划、UI、美术、音频和后续 Godot 场景接线共同使用。

适用范围：

- 唯一剧情：`mvp_story_01`
- 唯一地图：`mvp_map_01`
- 唯一战斗流程：开场 → 战斗内触发 → 胜利/败北结算

## 2. 演出约定

### 2.1 画面约定

- 旁白行不显示角色立绘，只显示文本框与深色背景
- 角色对话默认显示对应立绘与名称条
- 同一段内未明确切换时，沿用上一条立绘状态
- 战斗内触发对话默认暂停玩家输入，对话结束后恢复战斗

### 2.2 音频约定

- BGM 切换默认带淡入淡出
- 对话推进播放 `sfx_dialog_next`
- 重要事件触发时允许附加一条短提示音，但 MVP 可先省略

### 2.3 镜头约定

- 开场剧情使用全屏对话模式，不进入战斗镜头
- 地图加载后镜头先聚焦玩家单位区域
- 战斗内事件触发时，镜头优先聚焦触发单位或头目
- 结算剧情可回到全屏对话模式

## 9. 实施优先级

### P0 必做

- 开场剧情完整可播
- 山地边缘触发对话
- 胜利/败北结算可播
- BGM 三段切换：准备、战斗、胜利/败北

### P1 建议做

- 头目半血事件
- 头目死亡事件
- 表情切换
- 镜头聚焦

### P2 可后补

- 更复杂的立绘入场动画
- 打字机速度变化
- 分支选择

## 10. 验收点

1. 所有剧情事件只触发一次，不重复播放
2. 战斗内对话结束后，玩家输入恢复正常
3. BGM 切换点与文本情绪一致
4. 立绘缺失时可回退为纯文本，不阻塞流程
5. 胜利和败北都能走完整闭环
