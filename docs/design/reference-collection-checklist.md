# 参考素材收集清单

## 1. 目的

本文档用于指导团队在正式制作资源前收集参考素材，确保地图、角色、UI、音频不会各自跑偏。这里的“参考素材”只用于统一方向，不用于照搬。

## 2. 总原则

- 每类参考控制在少量高质量样本，不要堆一大堆图
- 每个参考都必须说明“参考什么，不参考什么”
- 如果两个参考冲突，以 `mvp-style-benchmark.md` 为准
- 参考素材服务于首关 MVP，不为未来大规模内容预埋过多风格包袱

## 3. 收集分类

### 3.1 地图参考

建议数量：3 张

需要关注：

- 格子可读性
- 地形差异
- 山道氛围
- 平原/森林/山地的色彩层次

不需要关注：

- 超复杂地图装饰
- 大规模动态天气

## 4. 参考素材收集顺序

建议按下面顺序收集：

1. 地图参考
2. UI 参考
3. 角色参考
4. 音频参考

原因：

- 地图与 UI 最直接影响“能不能看清”
- 角色风格要跟地图和 UI 一起看才稳
- 音频最后收，更容易贴合已定视觉气质

## 5. 收集后要做的判断

每个类别收完后，只保留这三种结论：

- `保留`：可以作为主参考
- `部分吸收`：只借其中一两个点
- `淘汰`：方向不适合 MVP

不要停留在“都挺好看”的模糊状态。

## 7. 当前建议

如果只能先收第一批参考，我建议先把下面 4 个问题回答清楚：

1. 地图到底更接近“自然边境山道”还是“浓幻想秘境”？
2. UI 到底更偏“传统战棋面板”还是“现代轻量极简”？
3. 玩家与敌方角色的颜色对比要拉到多强？
4. 战斗 BGM 是偏“轻史诗推进”还是“高热血爆发”？

这 4 个问题一旦定下来，后面大多数资源选择都会顺很多。
