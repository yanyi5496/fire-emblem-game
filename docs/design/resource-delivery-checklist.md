# 首批资源交付验收表

## 1. 目的

本文档用于验收首批资源交付结果，尤其适用于 M1 “可玩占位包”和 M2 “首关联调包”。目标不是评价美术好不好看，而是确认资源能否被 Godot 侧直接接入、不阻塞联调。

## 2. 验收原则

- 先验“能不能用”，再验“够不够好看”
- 与文档不一致的资源，即使看起来不错，也先记为不通过
- 占位资源允许简陋，但不允许不可读、不可替换、不可命名

## 3. 通用验收项

每个资源都先检查以下 8 项：

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| G01 | 文件名正确 | 符合 `naming-conventions.md` |
| G02 | 分类正确 | 放在正确目录类别 |
| G03 | 分辨率正确 | 与任务包/资源计划一致 |
| G04 | 可读性合格 | 在目标场景中可辨认 |
| G05 | 风格不冲突 | 不明显偏离风格基准 |
| G06 | 可替换性合格 | 后续正式版可无缝替换 |
| G07 | 透明/边缘正常 | 无明显白边、黑边、裁切异常 |
| G08 | 备注完整 | 如有特殊说明，已附交付备注 |

## 4. Tile 资源验收

| 资源 ID | 必查项 | 通过标准 |
|---|---|---|
| `tile_plain` | 平铺效果 | 连续铺开不刺眼 |
| `tile_forest` | 差异度 | 与平原明显区分 |
| `tile_mountain` | 危险感 | 与平原/森林明显区分，仍能看清单位 |

额外检查：

1. 三种地形叠在同一地图上时，单位和高亮不会被吃掉
2. 色彩饱和度不过高
3. 不出现误导性的障碍视觉

## 5. 单位资源验收

| 资源 ID | 必查项 | 通过标准 |
|---|---|---|
| `sprite_hero_001` | 主角识别 | 一眼看出近战主角 |
| `sprite_hero_002` | 支援识别 | 一眼看出非前排角色 |
| `sprite_enemy_001` | 敌兵识别 | 与玩家阵营明显区分 |
| `sprite_enemy_002` | 头目识别 | 与普通山贼明显区分 |

额外检查：

1. 缩放到战场实际尺寸后仍清楚
2. 玩家蓝系、敌方红棕系的大方向成立
3. 不依赖文字标签才能辨识阵营

## 7. 音频资源验收

| 资源 ID | 必查项 | 通过标准 |
|---|---|---|
| `bgm_battle_theme` | 循环性 | 可循环，不突兀 |
| `sfx_menu_confirm` | 操作反馈 | 短促清晰 |
| `sfx_menu_cancel` | 操作反馈 | 与确认音可区分 |

| `sfx_attack_axe` | 武器感 | 比剑更重 |
| `sfx_hit` | 命中感 | 有接触反馈 |

额外检查：

1. 音量基线接近，不会一个特别炸一个特别小
2. 不带明显杂音
3. 与战棋风格不冲突

## 8. 字体资源验收

| 资源 | 必查项 | 通过标准 |
|---|---|---|
| 中文主字体 | 可读性 | UI 与对白中均清楚 |
| 粗体/标题字体 | 兼容性 | 数字、标题、短标签都稳定 |

额外检查：

1. 不缺常用中文字符
2. 数字 `0-9` 清晰
3. 中英混排不突兀

## 10. 三种结果定义

| 结果 | 含义 | 后续动作 |
|---|---|---|
| Pass | 可直接入库并联调 | 进入下一环节 |
| Revise | 可用但需小修 | 反馈修改后复验 |
| Reject | 当前不可用 | 退回重做 |

## 11. 当前建议

首批资源验收时，最先验这条链路：

`tile_plain/forest/mountain -> sprite_hero_001/002 -> sprite_enemy_001/002 -> ui_cursor -> ui_highlight_* -> 中文字体 -> bgm_battle_theme`

只要这条链路全部 `Pass` 或最多少量 `Revise`，就足够支持后续 Godot 首轮联调。
