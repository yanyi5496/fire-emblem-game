# MVP 数值推演与平衡笔记

## 1. 概述

本文档对 MVP 数据包的各个战斗场景做数值推演，验证战斗公式在 MVP 范围内的闭环正确性，并为后续调参提供基准。

## 2. 关键公式回顾

所有公式以 `combat-system.md` 为准。

### 物理伤害
```
damage = max(0, STR + WeaponMight + TriangleBonus - (DEF + TerrainDefenseBonus))
```

### 魔法伤害
```
damage = max(0, MAG + WeaponMight - RES)
```

### 命中率
```
hit_rate = clamp(WeaponHit + SKL*2 + LUK + TriangleHitBonus + HeightBonus
                 - (targetSPD/2 + targetLUK + TerrainAvoidBonus), 0, 100)
```

### 暴击率
```
crit_rate = min(SKL / 2 + WeaponCrit, 50)
```

### 攻击速度 (ASPD)
```
ASPD = max(0, SPD - Weight)
```

### 追击条件
```
attackerASPD >= defenderASPD + 4
```

### 克制修正
| 情况 | TriangleDamageBonus | TriangleHitBonus |
|---|---|---|
| 剑 vs 斧（优） | +1 | +15 |
| 斧 vs 剑（劣） | -1 | -15 |
| 无克制 | 0 | 0 |

## 3. 核心对阵推演

### 3.1 艾克 (hero_001) 攻击 山贼 (enemy_001)

**攻击方：艾克**
- 武器：iron_sword (Might=5, Hit=90, Crit=0, Weight=5)
- STR=7, SKL=6, SPD=7, LUK=5, DEF=4
- ASPD = max(0, 7-5) = 2

**防守方：山贼**
- 武器：iron_axe (Might=8, Hit=75, Crit=0, Weight=8)
- STR=8, SKL=3, SPD=4, LUK=2, DEF=5
- ASPD = max(0, 4-8) = 0

**克制关系：剑 > 斧，艾克优势**

**命中率计算（双方都在平原）：**
```
hit_rate = 90 + 6*2 + 5 + 15 - (4/2 + 2 + 0)
         = 90 + 12 + 5 + 15 - (2 + 2 + 0)
         = 122 - 4 = 118 → clamp 100
```
命中率 100%，必定命中。

**伤害计算（双方都在平原）：**
```
damage = max(0, 7 + 5 + 1 - (5 + 0)) = max(0, 13 - 5) = 8
```
艾克每次攻击造成 8 点伤害。山贼 HP=20，需 3 次攻击击杀。

**暴击率：**
```
crit_rate = min(6/2 + 0, 50) = 3%
```

**追击检查：**
```
艾克 ASPD(2) >= 山贼 ASPD(0) + 4?  →  2 >= 4?  否
```
艾克不追击。

**反击（山贼存活时）：**
```
山贼命中率 = 75 + 3*2 + 2 - 15 - (7/2 + 5 + 0)
           = 75 + 6 + 2 - 15 - (3 + 5 + 0)
           = 68 - 8 = 60%
山贼伤害 = max(0, 8 + 8 - 1 - (4 + 0)) = max(0, 15 - 4) = 11
```
山贼反击命中率 60%，伤害 11。

**结论：**
- 艾克攻击山贼：必定命中，伤害 8。山贼反击概率 60%，伤害 11
- 艾克 HP=18，山贼 HP=20。艾克需 3 回合正面击败山贼，但自身有危险
- **建议战术：利用森林 +20 回避减少山贼反击命中率**

### 3.2 山贼攻击艾克（攻方在森林）

**场景：** 山贼在 forest，艾克在 plain

**山贼命中率：**
```
命中率 = 75 + 3*2 + 2 - 15 + (-10) - (7/2 + 5 + 0)
       = 75 + 6 + 2 - 15 - 10 - (3 + 5 + 0)
       = 58 - 8 = 50%
```
说明：山贼攻低守高（forest height=1 > plain height=0），命中 -10，降到 50%。

### 3.3 艾克在森林防御山贼

**场景：** 艾克在 forest (avoid_bonus=20, defense_bonus=1)

**山贼攻击艾克：**
```
命中率 = 75 + 6 + 2 - 15 - (7/2 + 5 + 20)
       = 68 - (3 + 5 + 20) = 68 - 28 = 40%
伤害 = max(0, 8 + 8 - 1 - (4 + 1)) = max(0, 15 - 5) = 10
```

**结论：** 站在森林使山贼命中率降为 40%，艾克可安全输出。

### 3.4 艾克攻击山贼头目 (enemy_002)

**攻击方：艾克**（数据同上）

**防守方：山贼头目**
- 武器：iron_axe
- STR=11, SKL=5, SPD=5, DEF=7, LUK=3, HP=28
- ASPD = max(0, 5-8) = 0

**命中率（都在平原）：**
```
命中率 = 90 + 12 + 5 + 15 - (5/2 + 3 + 0) = 122 - (2 + 3 + 0) = 117 → 100%
```

**伤害：**
```
damage = max(0, 7 + 5 + 1 - (7 + 0)) = max(0, 13 - 7) = 6
```
每次伤害 6，头目 HP=28，需 5 次攻击。

**头目反击：**
```
头目命中率 = 75 + 5*2 + 3 - 15 - (7/2 + 5 + 0) = 88 - (3 + 5) = 80%
头目伤害 = max(0, 11 + 8 - 1 - (4 + 0)) = max(0, 18 - 4) = 14
```

**触发 tough_body：** 头目被攻击后 def +3 → DEF 变为 10

```
第二次攻击伤害 = max(0, 13 - 10) = 3（大幅降低）
```

**结论：**
- 艾克 solo 头目非常困难：每次被反击 14 伤害，且两次后头目防御 +3
- HP 18 的艾克最多承受 1 次反击，必须靠琳娜治疗
- **建议战术：艾克先清理山贼，再联合琳娜消耗头目**

### 3.5 琳娜治疗

**治疗效果（按当前数据定义）：**
```
heal_light.effect.value = 10
```
- 当前 MVP 采用技能数据中的固定治疗值，不额外引入 `MAG + 常数` 的独立治疗公式
- 琳娜本次治疗量固定为 10
- heal_staff 耐久每次消耗 1
- 可治疗范围 1~2 格

### 3.6 山贼 vs 琳娜

**场景：** 山贼攻击琳娜

**山贼命中率（琳娜在 plain）：**
```
命中率 = 75 + 6 + 2 - (5/2 + 6 + 0) = 83 - (2 + 6) = 75%
伤害 = max(0, 8 + 8 - 1 - (2 + 0)) = max(0, 15 - 2) = 13
```
琳娜 HP=14，一次攻击即濒死。**务必保证琳娜远离敌人射程。**

## 6. 平衡调整指导

### 6.1 如果玩家过强

- 提升 enemy_001.level 到 2（HP 23, STR 9, DEF 6）
- 给山贼增加铁斧以外的第二把低耐久武器
- 在森林格增加一个额外山贼（enemy_001 克隆）

### 6.2 如果玩家过弱

- 降低 enemy_001.HP 到 18
- 降低 enemy_002.level 到 2（HP 24, STR 10）
- 给琳娜初始携带一根治疗杖（增加续航）

### 6.3 调参优先顺序

1. 调整单位 `stats`（最安全，不破坏结构）
2. 调整武器 `might`/`hit`（影响全游戏，需谨慎）
3. 调整地形 `avoid_bonus`（影响全局策略）
4. 调整 `growth_rates`（仅影响升级，MVP 中用不到）
