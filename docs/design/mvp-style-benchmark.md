# MVP 风格基准板文档

## 1. 目的

本文档用于统一 Project Ember 在 MVP 阶段的视觉与听觉方向，避免后续资源来自不同人时出现风格割裂。它不是美术圣经，而是“首关可用”的统一参考。

适用范围：

- 首关 `mvp_map_01`
- 2 名玩家、2 名敌人
- 主菜单、战斗 HUD、对话框
- 首轮 BGM / SFX / VFX

## 2. 风格关键词

### 2.1 整体气质

- 朴素
- 紧张
- 清晰
- 有一点旧式战棋味道
- 不做过度华丽特效

### 2.2 应避免的方向

- 过度卡通、Q 版夸张
- 高饱和糖果色
- 科幻 UI 风格
- 过分阴暗压抑的魂系氛围
- 花哨到影响格子辨识的地面纹理

## 3. 视觉基准

### 3.1 地图与格子

目标印象：

- 一眼能看清格子边界
- 地形差异明显，但不抢单位存在感
- 首关地图像“边境山道”，不是奇幻秘境

建议方向：

| 地形 | 视觉气质 | 建议关键词 |
|---|---|---|
| 平原 | 温和、基础、可读 | 草地、泥路、简洁 |
| 森林 | 有掩护感 | 树影、深绿、压暗 |
| 山地 | 更高、更硬、更危险 | 岩石、灰棕、突起 |

### 3.2 单位角色

目标印象：

- 艾克像前排近战主角
- 琳娜像脆弱但可靠的支援角色
- 山贼像低级但真实有威胁的敌人
- 头目在体型或轮廓上明显强于普通山贼

建议方向：

| 角色 | 视觉重点 |
|---|---|
| 艾克 | 深蓝/钢灰、直线轮廓、剑士感 |
| 琳娜 | 浅色衣料、柔和轮廓、治疗感 |
| 山贼 | 棕/暗红、粗糙布料、压迫感 |
| 头目 | 更重的轮廓、更深的配色、更明显武器存在感 |

### 3.3 UI

目标印象：

- 简洁、实用、信息优先
- 带一点传统 SRPG 菜单味道
- 不靠炫酷玻璃拟态，不靠现代极简纯白卡片

建议方向：

| 元素 | 建议 |
|---|---|
| 面板 | 深色半透明底 + 清晰浅色描边 |
| 按钮 | 有明确 Normal/Hover/Pressed 三态 |
| 光标 | 高对比、不可太细 |
| 高亮 | 蓝=移动，红=攻击，绿=治疗，必须一眼区分 |
| 对话框 | 朴素、稳定、适合长文本阅读 |

## 4. 配色基准

### 4.1 主色建议

| 用途 | 建议颜色 | 备注 |
|---|---|---|
| 主菜单深底 | `#1F2A30` | 深青灰 |
| 面板底色 | `#24343C` | 稍亮于主背景 |
| 面板描边 | `#D8C89A` | 暖米金色，做旧式边框感 |
| 强调蓝 | `#5D86C9` | 移动范围 / 玩家信息 |
| 强调红 | `#C95D5D` | 攻击与危险提示 |
| 强调绿 | `#58A66A` | 治疗与恢复提示 |
| 文本主色 | `#F2F0E6` | 高可读暖白 |

### 4.2 阵营识别色

| 阵营 | 建议色 |
|---|---|
| 玩家 | 蓝系 |
| 敌方 | 红系 |
| 中立/NPC | 黄棕系 |

注意：

- 阵营色用于边框、旗标、名字条即可，不要把角色整张图涂成纯色
- 高亮色必须和阵营色区分开，避免视觉混淆

## 5. 字体与文本基准

### 5.1 字体方向

- 中文主字体优先稳重、易读、笔画清晰
- 不使用过于可爱或装饰性强的标题字
- 数字与属性显示优先可读性

### 5.2 文本风格

| 场景 | 文本风格 |
|---|---|
| 菜单 | 简短、直给 |
| 战斗信息 | 数值优先、少废话 |
| 剧情对白 | 简洁，不做大段文艺抒情 |
| 提示文本 | 明确说明成功/失败原因 |

## 6. 动效与特效基准

### 6.1 动效原则

- 轻量
- 易读
- 不拖回合节奏

### 6.2 建议表现

| 场景 | 建议表现 |
|---|---|
| 光标移动 | 短促位移 + 轻音效 |
| 回合切换 | 文字淡入淡出或短横幅 |
| 攻击命中 | 短闪白 + 命中特效 |
| 治疗 | 绿色上升粒子或圆环 |
| 死亡 | 短淡出或碎散，不拖太久 |

### 6.3 避免

- 屏幕大幅震动
- 过长镜头停顿
- 全屏高亮闪烁
- 高粒子量导致格子难看清

## 7. 音频基准

### 7.1 BGM 气质

| 场景 | 气质关键词 |
|---|---|
| 开场准备 | 边境、任务感、轻紧张 |
| 战斗 | 明确节奏、推进感、不过分热血 |
| 胜利 | 轻释放、短而清爽 |
| 败北 | 低沉、收束 |

### 7.2 SFX 气质

| 类型 | 建议 |
|---|---|
| 菜单音 | 清脆、短、不过刺耳 |
| 剑攻击 | 轻金属感 |
| 斧攻击 | 更重、更钝一点 |
| 命中 | 有接触反馈，不要像科幻枪声 |
| 治疗 | 清亮、上升感 |

## 8. 参考对齐方式

为了避免每个人理解不同，建议后续收集参考图/音频时按以下方式整理：

| 类别 | 每类建议数量 | 目标 |
|---|---|---|
| 地图参考 | 3 张 | 对齐地形可读性 |
| 人物参考 | 3 张 | 对齐角色比例与轮廓 |
| UI 参考 | 3 张 | 对齐面板与按钮风格 |
| 音乐参考 | 2 首 | 对齐战斗与结算氛围 |

注意：

- 参考素材只用于定方向，不要求直接模仿
- 如果出现冲突，以“格子可读性优先”压过“画面精细度”

## 9. MVP 风格通过标准

首轮资源只要满足以下条件，就算风格方向合格：

1. 玩家、敌人、地形、UI 高亮一眼能分清
2. 主菜单、战斗 HUD、对话框看起来属于同一款游戏
3. 战斗 BGM 与胜利/败北 BGM 情绪不打架
4. 地图不花，单位不糊，信息面板不抢戏
5. 立绘缺失时，整体风格也不会彻底崩坏

## 10. 当前建议

如果现在只能定一件事，我建议先把下面这套基准当作默认方向：

- 地图：低饱和自然色
- UI：深底暖边框的传统战棋面板
- 单位：轮廓清晰，玩家偏蓝、敌人偏红棕
- 音乐：轻史诗但不过度宏大
- 特效：短、清楚、服务信息反馈

这套方向最适合 MVP，也最不容易在 Godot 中被资源质量参差拖垮。
