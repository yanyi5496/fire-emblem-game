# MVP 测试清单

## 1. 概述

本文档定义 MVP 阶段的功能验收测试清单，用于手工测试和后续自动化测试用例设计。每个测试项标注优先级和对应的验收标准引用。

## 15. MVP 验收总检查

以下 6 项为 MVP 验收核心标准（来自 TOP_PRD §21.1）：

| 验收项 | 验证方法 | 关联测试 |
|---|---|---|
| 玩家从菜单进入一场战斗 | 新游戏 → 剧情 → 战斗场景加载 | M002, T001 |
| 玩家与敌方各完成至少一个完整回合 | 至少执行一轮 Player → Enemy → Round End | R001~R005 |
| 可完成移动、攻击、死亡、胜负判断 | 一次完整战斗闭环 | P003, B003, B008, R006 |
| 数据修改后影响单位与武器表现 | 改 STR 后伤害变化 | F002 |
| 退出后可从存档恢复基本战斗状态 | 存档 → 退出 → 加载 → 检查状态 | D002 |
| 全部 P0 测试无阻塞性问题 | 运行本节所有测试 | 全部 P0 测试 |
