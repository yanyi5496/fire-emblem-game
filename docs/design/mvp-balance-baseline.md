# MVP 数值基线（第一轮定版）

## 1. 目的

本文档在 `mvp-data-pack.md` 与 `mvp-balance-notes.md` 的基础上，给出 MVP 第一轮可执行数值基线。它不是新的规则文档，而是用于约束后续录数、手测和调参的统一目标。

适用范围：

- 唯一地图 `mvp_map_01`
- 2 名玩家单位、2 名敌方单位
- 4 把武器、3 个职业、3 个技能

## 2. 当前定版口径

### 2.1 战斗规则口径

- 伤害、命中、暴击、追击条件以 `combat-system.md` 和 `mvp-balance-notes.md` 为准
- 治疗量以技能数据定义为准，当前 `heal_light.effect.value = 10`
- 武器克制仅启用 `剑 > 斧 > 枪 > 剑`
- 地形只启用 `plain / forest / mountain`
- 高度差命中修正继续采用当前 MVP 口径

### 2.2 首版数据冻结项

以下数据在第一轮验证结束前不建议频繁改动：

| 类别 | 冻结项 |
|---|---|
| 单位 | 基础属性、初始等级、初始技能 |
| 武器 | 威力、命中、重量、耐久、射程 |
| 技能 | 治疗值、冷却、触发时机 |
| 地图 | 出生点、地形分布、胜负条件 |

## 3. 目标体验

### 3.1 玩家体验目标

- 首关应让玩家理解移动、攻击、治疗、地形收益四个核心概念
- 艾克应是主要输出单位，但不能无脑单刷头目
- 琳娜应提供明确价值，但不应成为纯数值碾压点
- 森林应产生“愿意争夺”的位置价值
- 山地应提供明确的视线与地形威胁感，但不应形成无法接近的卡点

### 3.2 难度目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 首次通关回合数 | 4~6 回合 | 熟悉机制但不拖沓 |
| 熟练玩家通关回合数 | 3~4 回合 | 存在优化空间 |
| 推荐阵亡数 | 0 | 首关不鼓励以减员换胜利 |
| 容错次数 | 1 次明显失误 | 例如艾克错误站位后仍可被治疗救回 |
| 头目战长度 | 2~3 次有效交战 | 需要配合，但不应形成持久战 |

## 5. 第一轮调参边界

### 5.1 允许调整

- `enemy_001.hp` 在 `18~22` 内微调
- `enemy_002.hp` 在 `24~30` 内微调
- `enemy_002.def` 在 `6~8` 内微调
- `heal_light.effect.value` 在 `8~10` 内微调
- `iron_axe.hit` 在 `70~80` 内微调

### 5.2 暂不建议调整

- 艾克与琳娜的职业定位
- 武器克制修正值
- 追击阈值 `+4`
- 地形种类和地形效果数量
- 首关胜利条件

## 6. 调参优先顺序

如果首关打起来不理想，按以下顺序调，不要同时动太多项：

1. 先调敌方 HP
2. 再调敌方命中
3. 再调头目 DEF 或技能数值
4. 最后才调玩家基础属性

原因：

- 调 HP 最容易理解，对玩家体感影响直观
- 调命中可以改变风险感，但不会破坏定位
- 调 DEF 和技能会改 Boss 身份感，需要谨慎
- 调玩家基础属性最容易影响整个后续成长体系

## 7. 验收阈值

第一轮数值基线通过，至少要满足以下 6 项：

1. 新手玩家在理解规则后可于 2 次尝试内通关
2. 艾克单独冲向头目时，通关成功率显著下降
3. 琳娜至少存在 2 次有意义的治疗决策
4. 森林格确实能降低前排换血风险
5. 头目比普通山贼有明显更高的威胁感
6. 通关过程不依赖暴击或极端低概率闪避
