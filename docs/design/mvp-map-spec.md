# MVP 地图规格 —— 山道遭遇战

## 1. 概述

本文档定义 MVP 唯一关卡「山道遭遇战」(mvp_map_01) 的完整地图规格，包括 TileMap 分层设计、地形属性、单位站位、AI 行为与胜负条件。

## 2. 地图概览

| 属性 | 值 |
|---|---|
| 地图 ID | mvp_map_01 |
| 地图名 | 山道遭遇战 |
| 尺寸 | 10 × 10 格（0~9 行列索引） |
| 地形类型 | 平原、森林、山地 |
| 出战单位 | 玩家 2 名，敌方 2 名（含 Boss） |
| 关卡类型 | 全歼 (rout) |
| 回合上限 | 20 |

## 3. 格子布局（俯视网格）

列号 0~9，行号 0~9。平面坐标系：`(col, row)`，左上角为 `(0,0)`。

```
     C0  C1  C2  C3  C4  C5  C6  C7  C8  C9
R0: [  ][  ][  ][  ][  ][  ][  ][  ][  ][  ]
R1: [  ][艾][林][  ][  ][  ][  ][  ][  ][  ]
R2: [  ][  ][森][森][  ][  ][森][森][  ][  ]
R3: [  ][  ][森][森][  ][  ][森][森][  ][  ]
R4: [  ][  ][  ][  ][山][山][  ][  ][  ][  ]
R5: [  ][  ][  ][  ][山][山][  ][  ][  ][  ]
R6: [  ][  ][森][森][  ][  ][森][森][  ][  ]
R7: [  ][  ][森][森][  ][  ][森][森][  ][  ]
R8: [  ][  ][  ][  ][  ][  ][  ][  ][贼][  ]
R9: [  ][  ][  ][  ][  ][  ][  ][头][  ][  ]
```

图例：
- `[  ]` = 平原 (Plain)
- `[森]` = 森林 (Forest)
- `[山]` = 山地 (Mountain)
- `[艾]` = 玩家·艾克 (hero_001)
- `[林]` = 玩家·琳娜 (hero_002)
- `[贼]` = 敌人·山贼 (enemy_001)
- `[头]` = 敌人·山贼头目 (enemy_002)

## 4. 地形数据

### 4.1 地形属性表

| 地形 | move_cost | avoid_bonus | defense_bonus | walkable | height |
|---|---|---|---|---|---|
| plain | 1 | 0 | 0 | true | 0 |
| forest | 2 | 20 | 1 | true | 1 |
| mountain | 3 | 10 | 2 | true | 2 |

### 4.2 高度差影响

| 场景 | 命中修正 |
|---|---|
| 攻方在 mountain(2)，守方在 plain(0) | +10 |
| 攻方在 plain(0)，守方在 mountain(2) | -10 |
| 攻方在 forest(1)，守方在 plain(0) | +10（仅高度差≥1 即触发） |

注意：高度差修正只看 height 绝对值差值 >= 1 就触发，不是看格子类型名。

## 5. TileMap 分层映射

参考架构蓝图中的分层设计，MVP 地图只需使用以下 4 层：

| 层名 | 内容 | 技术说明 |
|---|---|---|
| GroundTileMap | 地形底色 + 地面细节 | 主 TileSet，含 plain/forest/mountain |
| BlockTileMap | 阻挡标记 | MVP 无需阻挡层，留空 |
| EventTileMap | 事件点（撤离点等） | MVP 无需事件点，留空 |
| HighlightTileMap | 移动/攻击/治疗高亮 | 动态写入，不存静态数据 |

### 5.1 TileSet 资源配置

TileSet 至少包含以下 3 个 Tile：

| Tile ID | 名称 | 颜色标识 | 像素尺寸 |
|---|---|---|---|
| 1 | plain | 浅绿 #90B860 | 64×64 |
| 2 | forest | 深绿 #3A7A2A | 64×64 |
| 3 | mountain | 灰棕 #8A7A5A | 64×64 |

每个 Tile 在 TileSet 的 Custom Data 中附加地形属性（move_cost, avoid_bonus, defense_bonus, walkable, height）。

## 7. AI 行为规划

### 7.1 enemy_001（山贼 · Aggressive）

- AI 类型：Aggressive
- 行为：主动朝最近玩家单位移动，进入射程后攻击
- 最优路径：从 (8,8) 沿左上方通过森林区域逼近玩家

### 7.2 enemy_002（山贼头目 · Aggressive）

- AI 类型：Aggressive
- 行为：主动朝玩家移动，优先攻击 HP 最低的目标
- 技能：触发 `tough_body`（被攻击时 def +3）
- 注意：因 level 3 比 enemy_001 多属性，应作为优先威胁

## 8. 胜负条件

| 条件 | 触发 | 表现 |
|---|---|---|
| 胜利 | 全部敌方单位 `action_state=Dead` | 显示"胜利！"，进入结算流程 |
| 失败 | 全部玩家单位 `action_state=Dead` | 显示"败北…"，进入败北结算 |
| 回合耗尽 | 到达第 20 回合 Round End | 按失败处理 |

### 8.1 胜负判定时机

每次 `Round End` 阶段结束时检查。

## 9. 预期战斗流程

| 回合 | 预期行为 |
|---|---|
| Player Turn 1 | 艾克向右上移动，琳娜跟随治疗位。不可直接接触敌人（距离 6~7 格） |
| Enemy Turn 1 | 山贼和头目向左下移动，进入森林获得回避加成 |
| Player Turn 2 | 艾克攻击山贼（注意森林回避+20）。琳娜治疗后撤 |
| Enemy Turn 2 | 头目攻击艾克，tough_body 触发。山贼残血或已死 |
| Player Turn 3 | 收掉残血，攻击头目 |
| Enemy Turn 3 | 头目最后一搏 |
| Player Turn 4 | 清理战场，胜利结算 |
