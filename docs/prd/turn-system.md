# 回合系统 PRD

## 1. 概述

回合系统控制战场行动顺序和回合结算流程。系统以单位的 `action_state` 为核心，不单独设置“战斗阶段”。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 回合阶段

```text
Player Turn → Enemy Turn → NPC Turn → Round End → (循环)
```

### 2.1 Player Turn

- 玩家可操作所有己方单位
- 每个单位可执行：移动、攻击、技能、待机
- 全部单位 `Acted` 或玩家主动结束时进入下一阶段

### 2.2 Enemy Turn

- 所有敌方单位按 AI 行动
- 行动顺序由 AI 和关卡控制决定

### 2.3 NPC Turn

- 友方 NPC 按 Support AI 行动

### 2.4 Round End

| 事件 | 描述 |
|---|---|
| Buff Tick | 先处理增益持续时间变化 |
| Debuff Tick | 再处理减益持续时间变化 |
| 中毒伤害 | 之后处理持续伤害 |
| 自动回血 | 再处理恢复效果 |
| 技能冷却 | 最后处理主动技能冷却 -1 |
| 状态重置 | 存活单位的 `action_state` 重置为 `Idle` |

回合结束默认顺序：

```text
持续时间变化 → 持续伤害/恢复 → 技能冷却 → action_state 重置
```

## 3. 单位行动限制

- `Idle`：可移动，可攻击，可用技能
- `Moved`：不可再移动，可攻击、可用技能、可待机
- `Acted`：不可再行动
- `Dead`：不参与回合

## 4. 胜负判定

每次阶段切换时检查：

| 条件 | 结果 |
|---|---|
| 所有敌方单位死亡 | 胜利 |
| 所有玩家单位死亡 | 失败 |
| 指定单位死亡 | 失败 |
| 玩家到达撤离点 | 胜利 |
| 回合数超过限制 | 失败 |

## 5. 边界条件

| 场景 | 行为 |
|---|---|
| 所有单位提前结束行动 | 自动进入下一阶段 |
| 回合数量达到上限 | 触发失败条件 |
| 全场无可攻击目标 | 允许仅执行移动、待机或辅助技能 |
| 玩家强制退出 | 提示确认，未保存则丢失进度 |
