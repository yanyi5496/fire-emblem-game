# 单位系统 PRD

## 1. 概述

单位是战斗中的基础实体。每个单位具有属性、职业、装备、行动阶段和异常状态。单位数据由 JSON 定义并在 Godot 运行时加载为内存实例。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 属性定义

### 2.1 基础属性

| 属性 | 全称 | 范围 | 描述 |
|---|---|---|---|
| HP | 生命值 | 0~999 | 为 0 时单位死亡 |
| MP | 魔法值 | 0~999 | 使用技能消耗 |
| STR | 力量 | 0~30 | 物理攻击力 |
| MAG | 魔力 | 0~30 | 魔法攻击力 |
| SKL | 技巧 | 0~30 | 影响命中/暴击 |
| SPD | 速度 | 0~30 | 影响回避/攻击速度 |
| DEF | 防御 | 0~30 | 物理防御 |
| RES | 魔防 | 0~30 | 魔法防御 |
| LUK | 幸运 | 0~30 | 影响命中/回避 |
| MOV | 移动力 | 0~15 | 每回合可移动格数 |

## 3. 状态系统

### 3.1 行动阶段状态

| 状态 | 描述 | 效果 |
|---|---|---|
| Idle | 待命 | 可移动、可攻击、可用技能 |
| Moved | 已移动 | 不可再移动，可攻击/待机/用技能 |
| Acted | 已行动 | 本回合结束 |
| Dead | 死亡 | 从战场移除 |

### 3.2 异常状态

异常状态独立于行动阶段，以 `status_effects` 列表存储：

| 状态 | 描述 | 效果 |
|---|---|---|
| `Poison` | 中毒 | 每回合结束扣除最大 HP 的 10% |
| `Sleep` | 睡眠 | 无法主动行动，受攻击后解除 |
| `Paralysis` | 麻痹 | 无法主动行动 |
| `Silence` | 沉默 | 无法使用魔法与技能 |

### 3.3 叠加与互斥规则

- 同类异常状态默认不叠加，仅刷新持续时间
- 控制类异常 `Sleep` 与 `Paralysis` 同一时刻只保留一种
- `Silence` 可与控制类异常并存
- `Poison` 可与其他异常状态并存

### 3.4 运行时结构

```json
{
  "action_state": "Idle",
  "status_effects": [
    {
      "id": "poison",
      "duration": 3
    }
  ]
}
```

## 4. 成长系统

### 4.1 成长率

每个属性有独立的成长率（0~100），升级时随机判定是否增长。

### 4.2 升级逻辑

```text
升级时每项属性：
  生成随机数 0~99
  如果随机数 < 成长率 → 该属性 +1
```

### 4.3 职业修正

职业提供成长率修正值，单位实际成长率 = 基础成长率 + 职业修正。

## 5. Godot 实现约束

- 战斗中的单位实例应与模板数据分离
- `action_state` 适合由状态机或枚举驱动
- `status_effects` 适合用数组或字典列表管理持续时间
- UI、战斗、存档统一读取运行时实例，不直接修改模板 JSON

## 6. 边界条件

| 场景 | 行为 |
|---|---|
| HP 为 0 | 立即转为 `Dead`，移除战场 |
| 属性超出上限 | 锁定在最大值 |
| 升级时全属性满 | 显示提示，不再加点 |
| 未定义成长率 | 默认为 0 |
| 单位同时存在多个异常状态 | 合法，但需遵守同类不叠加与控制类互斥规则 |
