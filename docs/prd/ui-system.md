# UI 系统 PRD

## 1. 概述

UI 系统包含主菜单、战斗界面和设置界面。设计目标是与战斗、音频和存档系统保持同一套数据口径，便于 Godot 控件直接绑定。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 主菜单

| 选项 | 功能 |
|---|---|
| 新游戏 | 开始新游戏 |
| 继续游戏 | 加载最近存档 |
| 设置 | 进入设置界面 |
| 退出 | 关闭游戏 |

### 2.1 无存档状态

- `继续游戏` 灰显
- 显示“暂无存档”

## 3. 战斗 UI

### 3.1 HUD 元素

| 元素 | 描述 |
|---|---|
| 单位信息面板 | 显示 HP/MP/属性/装备/异常状态 |
| 攻击预览 | 显示预期伤害、命中、暴击、追击 |
| 回合提示 | 显示玩家/敌人/NPC 回合 |
| 行动菜单 | 移动、攻击、技能、待机、物品 |
| 小地图 | 概览全图，可选 |

### 3.2 光标交互

| 操作 | 功能 |
|---|---|
| 方向键/鼠标移动 | 移动光标 |
| 确认 | 选择单位/确认行动 |
| 取消 | 取消选择/回退 |
| 信息键 | 显示格子与单位信息 |

### 3.3 范围高亮

- 蓝色：可移动范围
- 红色：可攻击范围
- 绿色：可治疗范围
- 黄色：可选目标

## 4. 设置界面

| 设置项 | 选项 |
|---|---|
| 分辨率 | 预设分辨率列表 |
| 全屏 | 开/关 |
| 主音量 | 0~100 |
| BGM 音量 | 0~100 |
| SFX 音量 | 0~100 |
| 语音音量 | 0~100 |
| 语言 | 中文 / English |
| 按键设置 | 自定义按键 |

## 5. Godot 实现建议

- 战斗 UI 使用 `CanvasLayer`
- 范围高亮与地形信息分层渲染
- 攻击预览统一读取 `CombatManager` 的模拟结果，不在 UI 内重复计算

## 6. 边界条件

| 场景 | 行为 |
|---|---|
| 分辨率不支持 | 回退到默认分辨率 |
| 设置未保存退出 | 提示是否保存更改 |
| 单位死亡 | 信息面板关闭并刷新选中状态 |
| 窗口尺寸变化 | UI 自适应缩放 |
| 语言文件缺失 | 回退到中文 |
