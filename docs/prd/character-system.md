# 角色系统 PRD

## 1. 概述

角色是叙事实体，单位是战斗实体。角色系统用于承接剧情、立绘、招募与角色档案，不替代单位系统。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 角色与单位的关系

- 角色通过 `unit_id` 关联战斗单位模板
- generic enemy 可仅存在单位模板，不建立角色档案
- 剧情成长或强制转职可更换角色关联的 `unit_id`

## 3. 角色分类

- 可招募角色
- NPC 角色
- 敌人角色

## 4. 数据要求

- 角色档案只保存叙事信息与招募信息
- 战斗属性统一归属于单位系统
- 生死、招募、剧情标记应可被存档系统序列化
- 当前 MVP 不要求完整角色档案系统，允许仅保留最小的 `name + unit_id + 剧情标记`

## 5. 边界条件

| 场景 | 行为 |
|---|---|
| 角色无 `unit_id` | 视为纯剧情角色 |
| 已死亡角色进入后续剧情 | 根据剧情标记决定跳过或替换 |
| 多个角色关联同一 `unit_id` | 视为数据错误，启动时报错 |

## 6. 依赖关系

- [单位系统](./unit-system.md) — 角色关联的战斗模板
- [剧情系统](./story-system.md) — 驱动对话与分支
- [存档系统](./save-system.md) — 保存角色状态
