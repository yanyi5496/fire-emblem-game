# 动画系统 PRD

## 1. 概述

动画系统负责单位和战斗的视觉表现。使用 Godot 的 `AnimatedSprite2D`、`AnimationPlayer` 和 `Tween` 实现。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 动画类型

| 动画 | 触发条件 | 描述 |
|---|---|---|
| 待机 | 单位未行动 | 循环播放 |
| 行走 | 单位移动时 | 沿路径播放 |
| 攻击 | 单位攻击时 | 含命中帧 |
| 暴击 | 暴击触发时 | 特殊攻击表现 |
| 死亡 | HP 归零时 | 倒地或消失 |
| 技能 | 使用技能时 | 技能特效 |

## 3. 技术实现

```text
Unit
 ├── AnimatedSprite2D
 ├── AnimationPlayer
 └── Tween
```

## 4. 动画同步

- 战斗判定以 `CombatManager` 为准
- 动画通过命中帧同步表现
- 多段战斗按队列顺序播放
- 动画系统不定义逻辑规则，只消费战斗结果对象

## 5. 边界条件

| 场景 | 行为 |
|---|---|
| 动画资源缺失 | 使用占位表现并记录警告 |
| Hit frame 不存在 | 在动画结束时结算表现 |
| 死亡动画播放中 | 不可被中断 |
