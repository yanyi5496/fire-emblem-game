# 武器系统 PRD

## 1. 概述

武器是单位战斗的主要工具。武器分为 6 大类型，具有克制关系、射程区间和耐久度。武器数据以 JSON 存储在 `res://data/weapons/`，由 Godot 运行时加载。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 武器分类

| 类型 | 适用职业 | 射程 | 物理/魔法 |
|---|---|---|---|
| Sword | 剑士/骑士/飞行 | 1~1 | 物理 |
| Lance | 枪兵/骑士/飞行 | 1~1 | 物理 |
| Axe | 斧兵/部分高级职业 | 1~1 | 物理 |
| Bow | 弓箭手 | 2~2 | 物理 |
| Staff | 牧师 | 1~2 | 辅助 |
| Magic | 法师 | 1~2 | 魔法 |

## 3. 武器属性

| 属性 | 描述 | 典型范围 |
|---|---|---|
| Might | 威力，加到攻击力上 | 1~20 |
| Hit | 命中率修正 | 50~100 |
| Crit | 暴击率修正 | 0~30 |
| Weight | 重量，参与攻击速度计算 | 1~20 |
| MinRange | 最小射程 | 1~2 |
| MaxRange | 最大射程 | 1~3 |
| Durability | 耐久度，用尽后不可用 | 1~50 |

### 3.1 JSON 数据示例

```json
{
  "id": "iron_sword",
  "name": "铁剑",
  "type": "sword",
  "might": 5,
  "hit": 90,
  "crit": 0,
  "weight": 5,
  "min_range": 1,
  "max_range": 1,
  "durability": 40,
  "effective_tags": []
}
```

## 4. 武器克制

### 4.1 三角克制

```text
剑 → 斧
斧 → 枪
枪 → 剑
```

### 4.2 克制效果

- 优势：命中 +15，伤害 +1
- 劣势：命中 -15，伤害 -1
- 无克制关系：无修正

### 4.3 特攻

- Bow 默认对 `flying` 标签单位生效
- 特攻效果为最终伤害 × 1.5，向下取整

## 5. 耐久度

- 每次完成一次攻击或治疗动作消耗 1 点耐久
- 耐久度为 0 时该武器不可用
- 是否允许修复由单个武器配置控制
- MVP 阶段只要求支持耐久消耗与耗尽不可用，不要求武器修理系统

## 6. Godot 数据约束

- 射程统一使用 `min_range` / `max_range`
- 武器模板与单位装备实例分离
- UI 高亮、AI 评估、反击判定都读取同一套射程字段

## 7. 边界条件

| 场景 | 行为 |
|---|---|
| 无武器装备 | 不可执行普通攻击 |
| 武器耐久为 0 | 该武器不可用，需切换 |
| 攻击超出武器范围 | 不可选择为目标 |
| 职业不匹配 | 不可装备 |
