# 地图系统 PRD

## 1. 概述

地图系统是 SRPG 的基础。所有战斗都在格子地图上进行。地图使用 Godot TileMap 实现，每个格子具有独立地形属性，影响移动、命中与防御。

本系统服务于 2D TileMap 战棋主玩法，不承担 3D 场景交互职责。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. Tile 属性

| 属性 | 类型 | 描述 |
|---|---|---|
| `move_cost` | int | 可通行时的移动消耗 |
| `avoid_bonus` | int | 站在该格上的回避加成 |
| `defense_bonus` | int | 站在该格上的物理防御加成 |
| `walkable` | bool | 是否对普通地面单位可通行 |
| `height` | int | 地形高度，影响命中修正 |

### 2.1 JSON 数据示例

```json
{
  "id": "forest",
  "name": "森林",
  "move_cost": 2,
  "avoid_bonus": 20,
  "defense_bonus": 1,
  "walkable": true,
  "height": 1
}
```

## 3. 地形类型

| 地形 | move_cost | avoid_bonus | defense_bonus | walkable | height |
|---|---|---|---|---|---|
| 平原 | 1 | 0 | 0 | true | 0 |
| 森林 | 2 | 20 | 1 | true | 1 |
| 山地 | 3 | 10 | 2 | true | 2 |
| 河流 | 0 | 0 | 0 | false | -1 |
| 城堡 | 1 | 5 | 3 | true | 1 |
| 室内 | 1 | 0 | 0 | true | 0 |
| 火山 | 2 | -10 | 0 | true | 1 |
| 雪地 | 2 | 5 | 0 | true | 0 |

### 3.1 不可通行规则

- `walkable=false` 时，普通地面单位不可进入
- 飞行单位可忽略大多数地面阻挡，但仍受专用阻挡层限制

## 4. 地图功能

### 4.1 阻挡

- 普通阻挡：墙、树丛、深水
- 飞行阻挡：仅用于禁止飞行单位通过的特殊区域

### 4.2 地形加成

- `avoid_bonus` 进入命中/回避计算
- `defense_bonus` 进入物理伤害减免
- 地形加成始终由当前站位决定

### 4.3 高低差

- 攻高守低：命中 +10
- 攻低守高：命中 -10
- 高低差不直接禁止攻击

### 4.4 可破坏地形

- 栅栏、门等可被攻击破坏
- 破坏后切换为替代 Tile
- 变更需同步更新寻路缓存

### 4.5 事件点

- 触发对话
- 获得物品
- 刷新增援
- 触发分支条件

### 4.6 传送点

- 支持单向/双向
- 可配置使用次数

### 4.7 撤离点

- 指定单位进入后触发胜利条件

## 5. 地图规模

- 最大尺寸：64x64
- MVP 地图：10x10
- 当前 MVP 以单张小地图验证移动、战斗、AI 和胜负判断为主

## 6. Godot 实现建议

- 使用 TileMap 分层管理地形、阻挡、事件与高亮
- 对移动范围和攻击范围做缓存，避免每帧重算
- 大地图优先优化寻路与高亮刷新，不采用 3D LOD 方案

## 7. 边界条件

| 场景 | 行为 |
|---|---|
| 单位移出地图边界 | 不允许移动 |
| 两个单位重叠 | 不允许，每格最多一个单位 |
| 地形数据缺失 | 默认按平原处理并记录警告 |
| 可破坏地形被摧毁 | 立即刷新阻挡与寻路数据 |
