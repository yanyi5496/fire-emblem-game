# 音频系统 PRD

## 1. 概述

音频系统管理背景音乐、界面音效、战斗音效、环境音和配音。系统需要兼容 Godot 音频总线，并与设置界面使用同一套玩家可调参数。

关联主 PRD: [TOP_PRD.md](./TOP_PRD.md)

## 2. 音频分类

| 分类 | 描述 | 示例 |
|---|---|---|
| BGM | 背景音乐 | 地图 BGM、战斗 BGM、Boss BGM |
| UI | 界面音效 | 确认、取消、菜单滚动 |
| Combat | 战斗音效 | 攻击、命中、暴击、死亡 |
| Ambient | 环境音效 | 风声、水声、城镇氛围 |
| Voice | 角色语音 | 技能台词、剧情语音 |

## 3. 玩家设置项

统一使用 4 个设置项：

| 设置项 | 说明 |
|---|---|
| `master_volume` | 总音量 |
| `bgm_volume` | 背景音乐音量 |
| `sfx_volume` | UI、战斗、环境音共用音量 |
| `voice_volume` | 语音音量 |

```json
{
  "master_volume": 80,
  "bgm_volume": 70,
  "sfx_volume": 85,
  "voice_volume": 100
}
```

## 4. 功能

### 4.1 淡入淡出

| 场景 | 淡出时间 | 淡入时间 |
|---|---|---|
| 地图→战斗 | 1.0s | 0.5s |
| 战斗→地图 | 0.5s | 1.0s |
| 剧情→战斗 | 0.3s | 0.5s |
| 菜单→游戏 | 0.5s | 1.0s |

### 4.2 动态切换

| 状态 | BGM |
|---|---|
| 地图准备 | 准备阶段主题 |
| 普通战斗 | 普通战斗 BGM |
| Boss 战 | Boss 战 BGM |
| 剧情 | 当前章节剧情 BGM |
| 胜利 | 胜利主题 |
| 失败 | 失败主题 |
| 主菜单 | 主菜单 BGM |

### 4.3 音效池

- 支持多个同时播放的音效
- 同类音效最多 3 个同时实例
- 超出时覆盖最早实例

当前 MVP 只要求主菜单、地图、战斗的基础 BGM/SFX 切换，不要求复杂混音逻辑。

## 5. Godot 实现建议

- 使用 Audio Bus 管理 Master / BGM / SFX / Voice
- UI、Combat、Ambient 在运行时归入 SFX bus 或其子 bus
- 大型 BGM 使用流式加载

## 6. 边界条件

| 场景 | 行为 |
|---|---|
| 音频文件缺失 | 记录警告并静默跳过 |
| 同时播放过多音效 | 按优先级丢弃最低优先级实例 |
| 游戏暂停 | 暂停 BGM 和长时环境音 |
| 游戏失去焦点 | 降低或暂停 BGM，保留关键音效 |
